# Java Banking System 🏦

A simple Java application that demonstrates Object-Oriented Programming (OOP) concepts through a banking simulation using a Graphical User Interface (GUI).

## 📋 Features

* **Multiple Accounts** — Manage three bank accounts with different initial balances.
* **Deposit** — Add money to the selected account.
* **Withdraw** — Withdraw money if the balance is sufficient.
* **Balance Display** — View the current account balance.
* **Input Validation** — Prevent invalid amounts and insufficient-balance withdrawals.

## 📂 Project Structure

```text
Java-Banking-System/
└── BankDemo.java
```

* **`Bank`** — Manages account balances, deposits, and withdrawals.
* **`BankDemo`** — Provides the graphical interface using Java Swing.

## 🛠️ Technologies

* Java
* Java Swing
* Java AWT

## 🚀 Getting Started

**Prerequisites:** Java Development Kit (JDK).

Check your Java installation:

```bash
java -version
javac -version
```

## 💻 How to Run

Compile the program:

```bash
javac BankDemo.java
```

Run the application:

```bash
java BankDemo
```
